## Agent using the CLI

**As an agent invoking wyvern, I want a browsable command reference that matches in-binary help, so I can find flags, built-in commands, and shipped extension examples without guessing.**

v0.8.0 publishes `site/cli/index.html`, generated by **sc-docli 0.2.0** from `usage_message()` and the shipped extension registry. `gen-cli-model` writes the CliModel JSON. The workspace does not depend on the `sc-docli` crate. CI regenerates the page and fails if `fixtures/cli/wyvern-cli-model.json` or `site/cli/` drifts.
