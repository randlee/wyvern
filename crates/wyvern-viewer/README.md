# wyvern-viewer

Embedded URL viewer for [Wyvern](https://github.com/randlee/wyvern).

The `wyvern-viewer` binary opens a [wry](https://docs.rs/wry) window that loads a dialog URL served by `wyvern-host`. The `wyvern` CLI launches it as a sibling when the viewer mode is `embedded`.
