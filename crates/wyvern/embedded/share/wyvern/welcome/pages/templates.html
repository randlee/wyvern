Template wizard

Wyvern ships a bundled template catalog: pytest, GitHub Actions, NUnit, xUnit, BenchmarkDotNet, and two wizard authoring skeletons. Finish this page to open the picker. Applying a template is automatic workflow.post — there is no shipped cp -R install path.

The picker grid is driven by config.templates. Page JavaScript never scans share/wyvern/templates. Finish data includes template_id, variables, and output_path.
