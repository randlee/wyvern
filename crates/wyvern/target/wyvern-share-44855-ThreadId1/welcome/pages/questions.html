AskUserQuestion

Wyvern can replace Claude Code’s AskUserQuestion tool with a native question dialog. A PreToolUse hook maps the tool payload to {"type":"question","questions":[...]} and prints REQ-0067 answers.

Finish this page to open the hook installer. Finish reloads the wizard host — the Wyvern window closes and reopens. The same wyvern process continues; it is not a second launch from the shell. Choose Global and/or Repo (local) scopes there. Page JavaScript never reads or writes ~/.claude files — the CLI pre/post scripts do.
